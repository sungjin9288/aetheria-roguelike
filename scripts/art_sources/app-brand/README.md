# Aetheria App Brand Source

`aetheria-app-icon-master.png` is the immutable generated source for native and web app branding.

## Visual Contract

- Centered golden sword inside a broken teal aether rune.
- Deep charcoal background with restrained stone texture.
- No text, baked rounded corners, device frame, or watermark.
- Critical silhouette remains inside the central safe area for iOS and Android masks.

## Generation Prompt

Create a premium mobile game icon for Aetheria: one upright legendary golden sword centered inside a broken circular teal aether rune, rendered as polished high-end pixel art on a deep charcoal background. Keep a compact, symmetric silhouette readable at 48px. Use antique gold, cyan-teal, charcoal, and ivory highlights. Do not include text, letters, people, a UI frame, rounded corners, a white background, or a watermark.
