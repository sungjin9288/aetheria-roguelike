# v13 소스의 새 캐릭터 첫 귀환 관찰

## 범위와 방법

현재 build를 별도 `localhost:4414` preview와 `fresh-v13` 브라우저 세션에서 390×844로 직접 조작했다. 이름은 기본 제안값을 사용했다. 기존 저장을 지우거나 수정하지 않았으며, 이 세션에 QA 저장·전투·RNG를 주입하지 않았다. 브라우저 세션과 preview는 관찰 후 종료했고 저장은 삭제하지 않았다. 물리 기기 테스트와 사용자 리텐션 증빙은 아니다.

## 확인한 실제 흐름

1. 새 캐릭터 생성: Lv1, 200골드, HP178/178, MP52/52, EXP0/200.
2. `고요한 숲으로 첫 출발` 후 첫 지역 발견: 300골드, EXP25/200.
3. 첫 탐험에서 `마법의 흔적` 이야기를 만났다. `위험할 수 있다, 무시한다` 선택 뒤 이번 원정에서 미룬다는 안내가 표시됐다.
4. 두 번째 탐험에서 단단한 독버섯(HP115)과 전투했다. 강타로 MP52→42, 적HP115→92를 확인했다. 물약2→1 사용 후 회복과 반격이 처리됐고, 일반 공격은 적HP92→78로 반영됐다. 이후 화면의 기술 버튼으로 승리까지 진행했다.
5. 전투 보상은 EXP14·골드21, 종료 자원은 HP118/178·MP2/52. 이동 화면에서 시작의 마을을 선택해 정상 귀환했다.
6. 귀환 기록의 전투1·탐험2·성장EXP39·골드변화121·최저HP118(66%)·소모품1개가 관찰과 일치했다. 원정 기록은 약4분으로 표시됐으나, 이는 도구 호출과 관찰 시간이 포함된 값이지 일반 플레이 시간의 추정치가 아니다.
7. 귀환 기록에서 첫 임무 보상을 직접 받았다. 최종 골드521·EXP79/200, 보상 버튼 대신 `임무 고르기`가 표시됐다.
8. 새로고침 후 같은 골드·HP·MP·EXP 및 보상 수령 상태가 유지됐다. 보상 받기 버튼0개, 가로 넘침false를 확인했다.

## 오류와 아직 증명하지 않은 것

- 콘솔에는 `/api/ai-proxy` 404가3회 있었다. 로컬 `.env`의 `VITE_USE_AI_PROXY=true`와 API가 없는 Vite preview 조합을 확인했다. aiService는 실패 후 내장 fallback을 반환하며 이 관찰의 전투·귀환은 계속 진행됐다. 별도 유료 API 호출이나 서버 배포는 수행하지 않았다. 이것은 깨끗한 console0 증빙이 아니며, 배포 환경의 proxy 동작도 증명하지 않는다. 로컬 설정은 변경하지 않았다.
- 첫 귀환까지 레벨업과 새 장비 획득은 없었다. 이 짧은1회 관찰만으로 첫 세션의 성장·장비 선택 목표를 통과 처리하거나 밸런스를 변경하지 않는다.
- 장비 비교/장착, 반복 이야기 재등장 방지의 장기 관찰, offline/quota, background/foreground, restart, 중후반 콘텐츠는 이번 실제 세션의 검증 범위가 아니다. 전체 S5 및 전체 Goal은 미완료다.
