## Scope and method

The preceding coverage audit identified 14 early general monsters, 6 mine/cave/snow monsters, and 26 retained bosses without current small-size review evidence. `output/review-retained-monsters.py` renders this exact unique 46-name set in four batches (12/12/12/10), using the existing manifest runtime paths. Every input SHA-256 must match `src/data/monsterArtManifest.json`; every input must be RGBA 160×160. Original and runtime assets are read-only.

Each image is shown at 160, 46 and 32 pixels on dark and light backgrounds. Outputs are exclusive-create review artifacts, not runtime replacements:

- `output/playwright/retained-monster-review-1.png` through `retained-monster-review-4.png`
- `output/retained-monster-review-records.json`: exact numbered names, paths and full input SHA-256s

The owner initially opened all four sheets with viewer scaling. On continuation, all four were reopened with `detail: original` propagated to the image output; the tool returned the full 1040-pixel-wide sheets without resize notices. This closes the owner contact-sheet small-size inspection gap, but does not establish an in-game UI or device pass. Independent design acceptance remains separate.
