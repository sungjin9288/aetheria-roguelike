# 앱인토스 스토어 등록 초안

앱인토스 콘솔에 넣을 이름 · 소개 문구 · 등급 신청 참고 · 콘솔 자산의 초안이다. 문구와 이름은 소유자가 정한다.

- **수치 기준:** 모두 2026-10-21 `main` `5f5a0b72`의 데이터에서 셌다(`src/data`).
- **외부 규격:** 앱인토스 문서는 이 작업 환경에서 열 수 없었다(네트워크 정책). 콘솔 규격은 저장소 검증기와 검색 요약 기준이므로 콘솔 화면에서 다시 확인한다.
- **절차:** 등록 순서는 [앱인토스 샌드박스 런북](../qa/APPS_IN_TOSS_SANDBOX_RUNBOOK.md)을 따른다.

## 1. 앱 이름 (결정 필요)

- **식별자(`appName`):** `aetheria`(`apps-in-toss.config.ts`). 콘솔에서 쓸 수 있는지 먼저 확인한다.
- **표시 이름:** 한글로 정한다. 영어로 표기한 앱 이름은 검수 반려 사례가 있다(검색 요약). 예전 인계 문서의 'Aetheria'는 바꿔야 한다. 후보는 '에테리아'다.
- **게임 화면의 영어 로고:** 시작 화면 · 로딩 화면은 영어 로고 'AETHERIA'를 그린다(`IntroScreen` · `BootScreen` — Wave 134에서 남긴 예외). 검수에서 문제가 되면 그때 정한다.

## 2. 소개 문구 초안

**한 줄 소개(후보 셋):**

1. 쓰러지면 처음부터 — 다시 오르는 판타지 로그라이크
2. 18개 직업, 52개 지역 — 글과 픽셀로 떠나는 판타지 모험
3. 고르고, 싸우고, 쓰러지면 다시 — 판타지 로그라이크

**긴 소개:**

> 에테르가 흐르는 대륙. 시작의 마을을 떠난 모험가는 숲과 동굴, 용의 둥지와 마왕성을 지나 혼돈의 심연까지 내려갑니다.
>
> 쓰러지면 이번 여정의 레벨 · 장비와 가방 · 유물 · 임무와 이야기 · 도감이 처음부터 다시 시작됩니다. 정수로 새긴 영구 성장과 전설 각인 수집은 남습니다. 한 번의 판단이 여정 전체를 바꿉니다.
>
> **고르는 재미**
> - 탐험할 때마다 전투 · 이벤트 · 유물 · 떠돌이 행상인이 기다립니다. 정예와 보스는 나타날 때 가장 센 한 방을 미리 보여 줍니다. 싸울지 피할지는 당신이 정합니다.
> - 유물 67종과 조합 20가지. 강한 조합에는 대가가 따릅니다.
> - 모험가에서 시작해 갈라지는 18개 직업. 직업마다 강점과 약점이 다릅니다.
>
> **이어지는 이야기**
> - 본편 16장과 이야기 13개가 임무로 열립니다.
> - 임무 151개 · 업적 73개 · 전설 각인 25개.
>
> **끝나지 않는 여정**
> - 마왕을 쓰러뜨리면 계승합니다. 회차 규칙 카드 세 장 중 하나를 골라, 더 강해진 세계로 다시 떠납니다.
> - 52개 지역, 몬스터 254종(보스 47종).
>
> **결제 없이**
> - 이 버전에는 결제와 광고가 없습니다. 모든 것은 플레이로 얻습니다.
>
> 〔토스 빌드에 Firebase를 넣을 때만〕 **다른 모험가의 흔적**
> - 다른 모험가가 쓰러진 자리에서 그 망령과 싸워 유품을 되찾습니다. 순위표에서 처치 기록을 겨룹니다.

**문구 근거:**

| 문구 | 근거 |
|---|---|
| 남는 것 · 처음부터 다시 하는 것 | 사망 화면이 그리는 표(`getJourneySurfaceText('death', …)` — Wave 108 · 125) |
| 정예 · 보스의 한 방 미리보기 | Wave 88 · 111 |
| 떠돌이 행상인 | Wave 75 |
| 조합의 대가 | Wave 50 |
| 임무로 열리는 이야기 | Wave 128 |
| 회차 규칙 카드 세 장 | Wave 94 |
| 회차마다 강해지는 적 | Wave 73 |
| 결제 · 광고 없음 | 소유자 결정 2026-10-06, `tests/launch-no-payment-contract.test.js` |

AI 이벤트는 문구에 넣지 않았다. 기본 꺼짐이고, 켜려면 [개인정보 근거 문서](../legal/PRIVACY_POLICY_EVIDENCE.md) §2-3을 먼저 닫아야 한다.

## 3. 게임 등급 신청 참고

등급은 게임물관리위원회에 직접 신청하거나 스토어 자체등급분류를 거쳐 받는다. 결과는 콘솔 '게임 등급분류' 탭에 넣고 게임 접속 화면에 표시한다(검색 요약). 설문에 답할 때 필요한 사실은 아래와 같다. 등급을 미리 정하지 않는다.

| 항목 | 게임의 사실 |
|---|---|
| 폭력 | 검 · 마법으로 몬스터와 싸운다. 피해는 숫자와 문장으로 나온다. 상태이상 '출혈'이 문장으로 나온다. 몬스터 그림은 픽셀 그림이다(표현 수위는 그림을 보고 판단) |
| 공포 | 언데드 · 마족 계열 몬스터가 있다 |
| 사행성 모사 | 게임 골드로 하는 도박 이벤트 3종이 있다(수상한 상인의 내기 · 운명의 주사위 · 3장 카드 트릭 — `src/data/aiEventPools.ts`). 실제 돈 · 결제는 없다 |
| 이용자 간 상호작용 | 채팅은 없다. 〔Firebase를 넣을 때〕 순위표에 캐릭터 이름이 공개되고, 다른 차원의 묘비에서 다른 이용자의 캐릭터 이름이 보인다 |
| 이용자 입력 | 캐릭터 이름(16자)과 의견 보내기. 다른 이용자에게 보이는 것은 캐릭터 이름뿐이다 |
| 자동 생성 문장 | AI 이벤트는 기본 꺼짐이다. 켜면 생성 문장이 탐험 이벤트에 나온다 |
| 결제 · 광고 | 없다 |
| 개인정보 | [처리방침 초안](../legal/PRIVACY_POLICY_KO.md) |

## 4. 콘솔 자산 만들기

규격은 저장소 검증기가 정한다(`scripts/tossReleaseEvidence.mjs` — `review` 단계).

- **로고:** 600×600 PNG.
- **썸네일:** 1932×828 PNG. 콘솔 필수 항목이다(앱인토스 운영진의 커뮤니티 답변, 검색 요약).
- **세로 스크린샷:** 실제 플레이 화면 3장 이상. 세로가 더 길고, 서로 달라야 한다. 예전 후보는 636×1048을 썼고 이 스크립트도 같다.

예전 후보의 자산(`docs/evidence/toss/releases/aetheria-8db86a2-b18b2457/assets/`)은 지금 게임과 다르다. 다시 쓰지 않는다.

- 첫 숲의 강제 이벤트('마법의 흔적')가 들어 있다. Wave 127 뒤로는 임무로 시작해 그 자리에 나오지 않는다.
- 상태 표시줄이 Wave 133 이전 배치다.
- '[스토리]' 머리표가 있다.
- 썸네일 제목이 영어다.

**만드는 명령(후보 worktree에서):**

```sh
npm run build
node scripts/store/capture-toss-console-assets.mjs --out "$RELEASE_DIR/assets" --name 에테리아 \
  [--tagline "<한 줄 소개>"] [--hero <캐릭터 이름>] [--seed <정수>]
```

- **캡처 방식:** 프로덕션 빌드를 미리보기 서버로 띄우고, 테스트 API 없이 화면의 단추로만 플레이해 찍는다.
  - 순서: 새 게임 → 마을 → 첫 출발 → 탐험.
  - 찍는 장면: 마을 · 전투 · 전투 결과 · 이벤트(또는 유물 선택).
  - 난수는 시드로 고정한다. 같은 빌드와 같은 시드면 같은 장면이다. 장면이 마음에 들지 않으면 `--seed`를 바꾼다.
- **썸네일 · 로고 합성:** 아이콘 원본(`scripts/art_sources/app-brand/aetheria-app-icon-master.png`)과 방금 찍은 스크린샷을 HTML로 합성해 같은 브라우저로 찍는다. 이미지 라이브러리는 쓰지 않는다.
- **글꼴:** 명령을 돌린 기기의 시스템 글꼴을 쓴다. 콘솔에 올릴 최종본은 소유자 Mac에서 만든다(Apple 글꼴 — iPhone과 같다).
- **결과물:** `--out` 폴더에 PNG 6장과 `prepared-console-assets.json`(규격 · SHA 목록, `candidateId` · `releaseId`는 빈 값)이 생긴다.
- **커밋하지 않는다.** 이미지는 후보 폴더에만 두고, 증빙을 저장소에 남길 때 그 폴더와 함께 들어간다.

**업로드 뒤 `console-assets.json`으로 옮기기:**

```sh
node --input-type=module - "$RELEASE_DIR" <<'NODE'
import { readFile, writeFile } from 'node:fs/promises';
const dir = process.argv.at(-1);
const { assets } = JSON.parse(await readFile(`${dir}/assets/prepared-console-assets.json`, 'utf8'));
const { candidateId, releaseId } = JSON.parse(await readFile(`${dir}/deployment.json`, 'utf8'));
await writeFile(`${dir}/console-assets.json`, `${JSON.stringify(assets.map((row) => ({ ...row, candidateId, releaseId })), null, 4)}\n`);
console.log(`console-assets.json ${assets.length}행`);
NODE
```

- 콘솔에 올린 파일이 이 PNG와 같은지(SHA) 확인한 사람이 `console_assets_review` 게이트 영수증을 남긴다.

**2026-10-21 이 작업 환경의 초안:** `5f5a0b72` 빌드에서 시드 `20261021`로 만들었다.

- **장면:** 마을 · 전투(거미떼) · 전투 결과 · 이벤트(앞길 정찰).
- **검증:** 리허설 후보 폴더에 넣어 검증기의 파일 검사(PNG 디코딩 · 크기 · SHA)와 `review` 단계의 자산 규칙을 통과했다([런북](../qa/APPS_IN_TOSS_SANDBOX_RUNBOOK.md) §4).
- **글꼴:** 이 환경에는 Apple 글꼴이 없어 Pretendard로 그렸다. 글자 모양이 기기와 다르므로 구도 검토용이다.

## 5. 검수 대비

검색 요약 기준이다. 콘솔의 게임 체크리스트로 다시 확인한다.

- **앱 이름:** 한글이어야 한다(§1).
- **소리:** 게임에 소리가 없다. "앱으로 돌아왔을 때 배경음악이 다시 나오지 않음" 반려 사례는 해당되지 않는다.
- **등급:** 게임 접속 화면에 등급을 표시한다(§3).
- **개인정보 · 문의:** 처리방침 공개 주소와 문의 채널이 필요하다(런북 §0-7).
- **결제 · 광고:** 없다. 사업자 없이 출시할 수 있는 조건이다(런북 §0-6).
- **검수 기간:** 영업일 2 ~ 3일, 민감한 주제는 최대 1주일이다.
